## Consigna

Desarrollar un ecommerce en react o codeigniter con las siguientes paginas

### Home
- Mostrar un listado de productos

### Pagina detalle del producto
- Mostrar los datos mas destacados del producto
  - Nombre
  - Precio
  - Stock
  - Codigo

### Registro
- Formulario de registro con campos a criterio del estudiante

### Login
- Email
- Contraseña

---

### En el caso de utilizar React JS:

- Los productos pueden salir de un mock de datos en el mismo codigo o utilizar una api.
- Los formularios de registro y login pueden ser solo maquetado.

### En caso de usar CodeIgniter:

- Leer los productos de la base de datos y registro y login tambien deben utilizar la base de datos.
